navi units

Design note for multi-instance tip space over one shared store. Seeds: C_devops/navi_redux/. Runtime: navi_shell. Also navi_manifest_space.html.

Contract: URL park = http.GET; callin navi('…') = http.POST. Same resolution pipe (delimiter race, unit prefix, capture). See navi_shell/README.md — Park frames GET vs POST.

1. Vocabulary

  • Space — shared tip+bin store (IndexedDB / ~/.navi_shell).
  • Unit tip — navi:unit:NN (or aliased navi:<name>). Carries data.unit.mods, online, hash.
  • entry-plug — live-only on the JS object (navi.plug). Not an ib. Bond = unitIb + hash (+ stamp / last_seen in RAM). Runtime Ed25519 private key never leaves memory (non-extractable); every plug response includes publicKey + detached signature over the shown fields (verify with publicKey; publicKey cannot produce the signature).
  • Root navi — identity tip (uuid). Rel8ns to unit tips. Not the verb dump.
  • navi:unit — unit system tip: list, aliases, resolution, heartbeat.
  • navi:plug — surface for entry-plug. GET = signed presence; POST ping|touch|ensure. touch is memory-only (does not mut8 heartbeat).
  • navi:mod — registration ledger (parks[] with ib^gib). Not live mounts.

2. Admin bag retired

  • No navi:admin, no navi:shell, no root navi_root actions list.
  • Flat tips: navi:reseed, navi:factoryreset, navi:alias, navi:prune, navi:resolve, navi:heartbeat, navi:reindex.
  • navi.storage.kill(ib) / callin storage kill … — entry-plug + confirm; not GET.
  • Flat module parks: navi:surf, … — not navi:mod:….
  • Routing tips navi:mount / browse / unmount / surfrefresh → surf commands.

3. Registration ≠ session

navi:mod.parks[] = registered at least once (ledger + addr). Live claim = navi:unit:NN.data.unit.mods + live navi.mod.* on that instance.

4. Birth

  1. Plant seeds if missing.
  2. No entry-plug → mut8 navi:unit bookkeeping → plant navi:unit:NN (rel8 root + mint hash) → set entry-plug.
  3. Entry-plug already set → no second mint for this instance.

5. Callin / park

  • Explicit unit: navi/unit/01/surf/… or navi('unit/01/surf …').
  • Bare navi/surf/… → default unit from navi:unit resolution / last heartbeater / entry-plug.
  • Capture: deepest dispatchable park prefix (kind mod|surface|relay); remainder = args. Saved deeper tips must not steal navi:surf.
  • SW: X-Navi-Unit; park.check includes unit.

6. Heartbeat / alias / prune

  • Every interval_sec (default 180s): mut8 navi:unit — bonded entry-plug row gets heartbeat_at + online: true. Callin/relay do not pulse — they bind unit context from live entry-plug memory.
  • Other list rows whose heartbeat_at is older than stale_sec (default 240s) → online: false.
  • plug touch / bonded plug ensure: memory-only stamp/last_seen refresh + signed response. Does not mut8 navi:unit.
  • When navi:unit n reaches n_max (default 20): compact lineage — setTip to n=1 first, then drop older ib^gib frames; past← rolled-off + data.rollover. Unit instances untouched (use prune).
  • navi('prune offline') drops tips (entry-plug gated).
  • navi('alias 01 kitchen') → plant navi:kitchen, erase navi:unit:01, still bonded.
