Flow model documentation

The flow model is how foobarch / navi_shell products express user journeys: which screen comes next, what context carries forward, and how alternative journeys stay publishable and swappable without forking core logic.

Assumes current navi_shell: tip+bin storage, park callin, navi:mod remount, hostpark as default push host, local-first plant/park-check. Shell units / entry-plug are out of scope for flow products (one session per navi window).

Who this is for

Anyone publishing modules, HTML fragments, flow JSON, and launches onto hostpark and running them inside the navi shell.
